### Historias de Usuario - Actividad 1 (E-commerce)
1. **HU01 - Listado:** Como cliente, quiero ver el catálogo completo de productos con sus detalles y disponibilidad para elegir qué comprar.
2. **HU02 - Filtrado:** Como cliente, quiero filtrar los productos disponibles para no perder tiempo viendo artículos agotados.
3. **HU03 - Carrito de compras:** Como cliente, quiero agregar productos al carrito especificando cantidades para armar mi pedido.
4. **HU04 - Cálculo total:** Como cliente, quiero visualizar el subtotal y total de mi compra para conocer el costo final antes de confirmar.
5. **HU05 - Cancelación:** Como cliente, quiero tener la opción de vaciar o cancelar el pedido en cualquier momento para reiniciar mi compra si cambio de opinión.
