# poo_tp5_grupo12
Repositorio del grupo 12 destinado al desarrollo del TP N°5 de Programación Orientada a Objetos - APU (SP).


### Historias de Usuario - Actividad 1 (E-commerce)
1. **HU01 - Listado:** Como cliente, quiero ver el catálogo completo de productos con sus detalles y disponibilidad para elegir qué comprar.
2. **HU02 - Filtrado:** Como cliente, quiero filtrar los productos disponibles para no perder tiempo viendo artículos agotados.
3. **HU03 - Carrito de compras:** Como cliente, quiero agregar productos al carrito especificando cantidades para armar mi pedido.
4. **HU04 - Cálculo total:** Como cliente, quiero visualizar el subtotal y total de mi compra para conocer el costo final antes de confirmar.
5. **HU05 - Cancelación:** Como cliente, quiero tener la opción de vaciar o cancelar el pedido en cualquier momento para reiniciar mi compra si cambio de opinión.

### Historias de Usuario - Actividad 2 (Envíos)
1. **HU01 - Registrar Envío:** Como Encargado de Logística quiero registrar un nuevo envío indicando id, remitente, destinatario y dirección de entrega para ingresar el despacho al sistema.
2. **HU02 - Agregar Paquetes a un Envío:** Como Operador de Depósito quiero asociar uno o más paquetes (con su código, descripción, peso y volumen) a un envío registrado para consolidar la carga real que compone dicho despacho.
3. **HU03 - Asignar Envío a una Ruta Diaria:** Como Planificador de Rutas quiero asignar envíos que contengan paquetes a una ruta diaria asociada a un vehículo para organizar los repartos del día sin superar la capacidad máxima de peso en kg del vehículo.
4. **HU04 - Despachar y Actualizar Estado de Envío:** Como Conductor / Transportista quiero cambiar el estado de un envío a EN_RUTA, ENTREGADO o DEVUELTO según corresponda para mantener actualizado el ciclo de vida de las entregas en tiempo real.
5. **HU05 - Consultar Información Detallada de Envío:** Como Operador de Atención al Cliente quiero consultar los detalles de un envío específico por su ID para visualizar el estado actual, la dirección de entrega, los paquetes contenidos y la ruta asignada.
